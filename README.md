# UDISE+ Madhya Pradesh Education Data Analysis

## Project Overview
This project focuses on analysing district-level education data from the Unified District Information System for Education Plus (UDISE+) for selected districts of Madhya Pradesh.

The project demonstrates how government education data can be cleaned, organised, analysed, and visualised to support education monitoring, programme evaluation, and evidence-based policy research.

## Objectives
- Analyse available education indicators across selected districts.
- Organise and prepare datasets for analysis.
- Develop an interactive Power BI dashboard to explore education data.
- Demonstrate the use of administrative data for monitoring and decision-making.

## Tools and Technologies
- **Python (Pandas):** Data cleaning and preparation.
- **SQL:** Data querying and organisation.
- **Power BI:** Data visualisation and interactive dashboard development.

## Data Source
UDISE+ (Unified District Information System for Education Plus), Ministry of Education, Government of India.

## Key Skills Demonstrated
- Data cleaning and transformation
- Government data analysis
- Education indicator analysis
- Dashboard development
- Data-driven monitoring and evaluation
- Evidence-based policy analysis

## Limitations
The analysis depends on the availability, completeness, and consistency of the underlying datasets. The results highlight observed patterns and should not be interpreted as proof of causal relationships.

## Author
A project exploring the application of data analytics to education monitoring and public policy.
